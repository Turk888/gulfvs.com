## 🔍 How to Find Things

### Finding a Style
1. Open `css/styles.css`
2. Search for the element class name (Ctrl+F)
3. Edit the CSS properties

### Finding a Form
1. Open relevant HTML file (contact.html, index.html, blog.html)
2. Search for "form" (Ctrl+F)
3. Modify form fields as needed

### Finding Text to Translate
1. Open HTML file
2. Search for `data-en=` (Ctrl+F)
3. Add Arabic text in `data-ar=`

### Finding JavaScript Functionality
1. Open `js/main.js`
2. Search for function name (e.g., "formHandler")
3. Modify the function

### Finding a Color
1. Open `css/styles.css`
2. Search for `:root {` to find all colors
3. Change hex code
